# 끝말잇기 대모험

만 5~6세 아이를 위한 음성 기반 끝말잇기 학습 게임입니다. 아이가 순서대로 등장하는 AI 캐릭터(다람쥐 → 고양이 → 부엉이 → 여우 → 호랑이)와 끝말잇기로 대결합니다.

- 상대 캐릭터가 단어를 말하면(텍스트 + 그림 + 음성) 아이가 마이크로 이어지는 단어를 말합니다.
- 아동 수준 단어 사전(약 470여 개) 안에서만 정답을 판정하며, 시작 글자·사전 존재 여부·중복 여부를 검사합니다.
- 캐릭터마다 고유한 말투와 "막힘 확률"이 있어 난이도가 점점 올라갑니다.
- 답이 막히면 그림 힌트 → 초성 힌트 순으로 도와주고, "몰라요"를 누르면 정답을 보여주고 부드럽게 다음 라운드로 이어갑니다.
- "뜻풀이" 버튼으로 단어 뜻을 언제든 확인할 수 있습니다(게임 판정과는 무관한 학습용 기능).
- 진행 상황(이긴 캐릭터, 최고 기록)은 브라우저 localStorage에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

음성 인식은 Web Speech API를 사용하므로 크롬 계열 브라우저에서 마이크 권한을 허용해야 정상 동작합니다.

## 빌드

```bash
npm run build
```
